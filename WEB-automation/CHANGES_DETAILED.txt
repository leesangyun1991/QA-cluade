===============================================================================
SELECTOR PATTERNS USED
===============================================================================

Pattern 1: Partial CSS Module Class Match
  [class*="componentName"]
  Example: [class*="commonTextarea"] matches _commonTextarea_commonTextarea__DWYyY

Pattern 2: Multiple Fallback Chaining
  'selector1, selector2, selector3'
  Example: '[class*="feedRealTimeTab"][class*="pickTab"], button:has-text("PiCK")'

Pattern 3: Text-Based Selectors
  :has-text("Button Text")
  Example: button:has-text("작성하기")

Pattern 4: Conditional Count Checks
  if locator.count() > index:
      locator.nth(index).click()
  // Allows graceful skip if fewer elements than expected

Pattern 5: Optional Content Handling
  try:
      element = page.locator('...')
      if element.count() > 0:
          element.first.do_something()
      log_result(..., success=False)  // Skip gracefully
